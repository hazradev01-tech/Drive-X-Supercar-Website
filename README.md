# 🏎️ Drive X – Supercar Website

Welcome to **Drive X**, a modern, sleek, and responsive website dedicated to high-performance supercars. This project showcases dynamic UI design, interactive elements, and modern web styling designed for car enthusiasts.

---

## ✨ Features

- **Responsive Design:** Optimized for seamless viewing across desktop, tablet, and mobile devices.
- **Dynamic & Interactive UI:** Smooth user interaction built with custom JavaScript.
- **Modern Styling:** Eye-catching layouts and modern aesthetics implemented using pure CSS.
- **Fast & Lightweight:** Built using core web technologies without heavy dependencies.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic structure and layout.
- **CSS3:** Custom styling, responsive design, animations, and flexbox/grid layouts.
- **JavaScript (ES6+):** Interactive elements and dynamic DOM manipulations.
